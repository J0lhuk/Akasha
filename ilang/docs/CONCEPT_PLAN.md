# План концептуальной разработки ilang

Зафиксирован **после** сбора и проверки исследовательского порога 2026-10-11. Порог: ≥100 страниц GitHub Search API и ≥500 уникальных релевантных веб-страниц. Свидетельство: `../research/summary.json`; последующая редактура реестра сохраняет исключения и повторно проверяет порог.

Это отдельное направление Akasha. После исследования владелец уточнил цикл вопросов, сохранение именованного рецепта из работы, анализ результата и явно поручил: «Композиция skills — внедряй». План расширен продуктовым этапом P1–P4. Самостоятельный исполнитель внешних действий и автоматическое подключение ilang не создаются; выполнение плана поручается Codex через явный skill/MCP. Название «ультра мета скиллс» — рабочее определение владельца.

| Порядок | Работа | Проверяемый артефакт | Статус |
|---|---|---|---|
| C0 | Собрать корпус, проверить релевантность, дедупликацию, хэши; сравнить основные подходы | Реестр ≥100 / ≥500, журнал исключений, синтез с источниками | Выполнено: 100 / 573; SYNTHESIS.md |
| C1 | Разделить идею, skill, метаскилл, ультра метаскилл; сравнить концепции | CONCEPT.md, решение о базовом варианте | Выполнено |
| C2 | Определить минимальную семантику, типы, композицию, эффекты, версии и неоднозначность | LANGUAGE_FOUNDATIONS.md; строгие Go-структуры P1 вместо второго независимого описания схемы | Выполнено |
| C3 | Сформировать варианты метапромптинга и рабочие шаблоны | META_PROMPTING.md с шаблонами | Выполнено |
| C4 | Подготовить проверяемые определения, планы и изолированный сквозной пример | examples/, Go-валидатор, CLI fixture с локальным HTTP | Выполнено |
| C5 | Спроектировать опциональную интеграцию и программу измерений | INTEGRATION.md, EVALUATION.md, reports/VALIDATION.md | Выполнено |

Разработка выполняется по порядку. Изменение базового решения описывается в CONCEPT.md. Дополнительные источники могут уточнять решение, но не заменяют уже собранный корпус.

После C1–C3 выполняется внедрение, затем примеры C4 и измерения C5:

| Порядок | Работа | Проверка | Статус |
|---|---|---|---|
| P1 | Go: определения, неизменяемые версии, явное включение, композиция, вопросы до плана | Типы, зависимости, пределы, изоляция, отсутствие скрытых defaults | Реализовано, проверки Go пройдены |
| P2 | Сохраняемые запуски, ответы, мастер-промпт, анализ результатов, извлечение рецепта | Устаревшие ответы, неполные проверки, повторное использование | Реализовано, проверки Go пройдены |
| P3 | CLI, опциональные MCP tools, инструкция разговорного skill | Реальный CLI и MCP round-trip; по умолчанию прежний набор tools | Реализовано и проверено |
| P4 | Проверки Go/vet, сквозной пример, замеры, сборка | Воспроизводимый отчёт с границами доказательства | Выполнено; reports/VALIDATION.md |

Полноценный парсер свободной нотации, собственный автономный исполнитель, визуальный редактор, ультра-оптимизатор и доказательство экономии на рабочих проектах остаются будущими этапами.
